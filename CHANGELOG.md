# Changelog

Все заметные изменения проекта. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [SemVer](https://semver.org/lang/ru/).

## [2.0.5] — 2026-11-20

Стало спокойнее и понятнее.

### Изменено

- Один вид у всех экранов: одинаковые шрифты и заголовки в обеих темах, ничего мельче 11 px.
- Кнопки больше не бьют по глазам яркой заливкой — «Остановить обход» и остальные действия
  стали мягкими и одинаковыми во всех темах.
- «Главная» короче: сводка состояния, три карточки сервисов и одна строка обновлений вместо
  двух одинаковых блоков.
- Порты, ключ Telegram и логи убраны в «Дополнительно» — основное видно сразу.
- На широком окне содержимое по центру, а не прижато к меню.
- В списке стратегий убраны длинные строки параметров — остались название и результат.
- Убрана третья тема «Графит»; остались «Спутник» и «Кармин».

### Исправлено

- Ползунок «Подбор новых» в «Кармине» больше не обведён тёмной рамкой.
- В диалогах Tab не уходит за пределы окна, Esc закрывает, фокус возвращается на кнопку,
  с которой диалог открыли.

## [2.0.4] — 2026-11-19

### Исправлено

- **Ошибки `reg.exe` / `taskkill.exe — Ошибка приложения (0xc0000142)` при
  выключении ПК.** Реестр (системный прокси, `MachineGuid`, автозапуск, ключ
  службы) читается и пишется напрямую через Win32 API; в ветке завершения
  процессы больше не запускаются, очистка при выходе выполняется один раз.
- **Полоса прокрутки на странице VPN** больше не прилипает к локациям — отступ
  как у списка стратегий. Невидимые зоны ресайза убраны, поэтому скроллбар
  работает по всей ширине.
- **Растягивание окна** — нативная рамка Windows: окно тянется за невидимый
  край снаружи, как в остальных приложениях.

### Изменено

- Версия в `package-lock.json` приведена к `package.json`, убран дубль `shadow`.

## [2.0.3] — 2026-11-19

### Изменено

- **Обновлены зависимости.** `vitest` 3 → 5, `vue-tsc` 2 → 3, `@tauri-apps/cli`
  2.11 → 2.12, крейт `zip` 2 → 9; остальные npm-пакеты и Rust-крейты подтянуты
  до актуальных версий (`rustls`, `rustls-webpki`, `quinn-proto`, `webpki-roots`,
  `rustix`). Для приложения это ничего не меняет — только версии под капотом.
- **Сборка больше не печатает предупреждение `STATIC_VCRUNTIME`.** Новый Tauri CLI
  управляет статической линковкой CRT через `build.windows.staticVCRuntime`;
  портабельный `Splitline.exe` по-прежнему работает без установленного
  Visual C++ Runtime.

### Безопасность

- **Проверка зависимостей в CI.** Джоба `Dependency audit` падает на уязвимостях
  в npm- и Rust-зависимостях; локально то же самое делает `npm run security`.
  Dependabot следит за npm, cargo и версиями GitHub Actions.
- **Закрыты известные уязвимости.** В `vitest` 3 приходил critical `tinypool`
  (prototype pollution с переходом в исполнение кода), в `vue-tsc` — цепочка
  `minimatch`, в `zip` 2 — path traversal при распаковке архива.

## [2.0.2] — 2026-11-18

### Исправлено

- **Автопоиск доменов при добавлении сайта.** Добавление сайта перезапускает туннель, и
  первый запрос мог уйти в ещё не поднявшийся прокси: показывалось «Не удалось загрузить
  <сайт>», хотя сайт уже был добавлен. Теперь запрос повторяется до трёх раз, а в тексте
  ошибки видна настоящая причина — таймаут, отказ соединения или код ответа.
- Сообщение об ошибке автопоиска больше не выглядит как отказ добавления: сайт остаётся в
  списке, а текст говорит, что не удалось только проверить дополнительные домены.
- **«Ядро: не установлено» при работающем VPN.** Версия ядра читается из самого бинарника,
  если в конфиге она пустая; до этого показывается «установлено», а не «не установлено».
- **Предупреждение «Браузеры идут мимо VPN».** Если туннель включён, а системный прокси
  выключен, на странице VPN появляется карточка с кнопкой «Включить»: иначе браузеры
  открывают заблокированные сайты напрямую, и это выглядит как «VPN не работает».
- **Два тумблера наверху страницы VPN.** «VPN для Telegram» поднимает туннель, «VPN для
  сайтов» включает системный прокси и при необходимости сам поднимает туннель. Раньше
  главный переключатель выглядел как «VPN вообще», хотя браузеры зависели от настройки
  в отдельной карточке.

## [2.0.1] — 2026-11-18

### Добавлено

- **Окно загрузок.** Пока качается ядро Xray, списки доменов, обновление flowseal-zapret,
  Telegram-прокси или обновление приложения, в правом нижнем углу видна небольшая карточка:
  название, полоса прогресса, проценты и объём. Если сервер не сообщил размер, полоса
  показывает, что загрузка идёт. Ошибка остаётся в той же карточке и не исчезает сразу.

### Изменено

- **Приложение запоминает, что было включено.** При запуске восстанавливается последнее
  состояние: обход (с последней стратегией), VPN и Telegram-прокси включаются, если были
  включены при выходе, и остаются выключенными, если были выключены. Это работает при любом
  запуске, не только при автозапуске Windows.

### Удалено

- Тумблеры «Подключать VPN вместе с приложением» и «Запускать прокси вместе с приложением» —
  их роль теперь выполняет сохранённое состояние.

## [2.0.0] — 2026-11-18

Крупное обновление: VPN по подписке. Всё, что было в 1.6.1, работает как раньше.

### Добавлено

- **VPN по подписке.** Новая страница: ссылка от провайдера, список локаций с задержкой,
  подключение, отключение, перезапуск, логи, автозапуск и свои порты. Ядро — официальный
  Xray, скачивается с проверкой SHA-256; устройство определяется по `MachineGuid`, поэтому
  лимит провайдера не расходуется.
- **Туннель только для выбранных сайтов.** Браузеры идут через системный прокси Windows,
  Telegram — через SOCKS по ссылке `tg://socks`. Всё, чего нет в списке, открывается
  напрямую, как без VPN.
- **Наборы сервисов.** Instagram (вместе с CDN), Discord, TikTok, YouTube, Twitter / X,
  Facebook, ChatGPT, Rutracker, Telegram, WhatsApp, Reddit, Spotify, LinkedIn — один пункт
  вместо списка доменов. Кнопка «Обновить базы» скачивает и объединяет списки v2fly и
  Loyalsoldier.
- **Автопоиск доменов.** При добавлении сайта приложение открывает его через туннель и
  предлагает хосты, без которых страница не соберётся.
- **Импорт и экспорт списка сайтов** в текстовый файл.
- **Статус VPN в шапке**: «VPN включён», «Telegram и VPN работают» и т. п.

### Изменено

- Страница VPN собрана в одну карточку подписки: ссылка, «Обновить подписку», «Замерить пинг»,
  «Перезапустить» и список локаций.
- Один тумблер «Браузеры через VPN». Если Telegram работает через MTProto-прокси, появляется
  подсказка с кнопкой «Переключить на VPN» — молча ничего не меняется.
- Иконка приложения в палитре carmine, включая значок в трее.

### Исправлено

- Скачивание ядра на медленном канале: свой таймаут, потоковая запись, повторы. Плюс
  установка из вручную скачанного архива, если GitHub недоступен.
- Первый запуск без установленного ядра больше не зависает.
- Ошибка с текстом на русском больше не роняет приложение.
- Маршрут Telegram дополнен диапазонами медиа-серверов — часть соединений уходила мимо VPN.
- Системный прокси: настройки Windows восстанавливаются при остановке и при падении ядра.
- Белый список больше не зависит от того, как провайдер назвал прямой outbound, и не
  отключается, если в подписке есть скрипт маршрутизации.
- Меньше задержек на новых доменах: убран лишний DNS-резолв при маршрутизации.
- Занятый порт показывает, какая программа его держит, вместо остановки всех `xray.exe`.

### Ограничения

- Голос Discord идёт по UDP мимо прокси — для звонков нужен zapret (приложение предупреждает).
- Режима TUN нет: через VPN идут браузеры и Telegram, остальные приложения — напрямую.

## [1.4.0] — 2026-11-11

### Добавлено

- Новая тема **«Спутник»** — тёмно-синий «орбитальный» интерфейс с циановым акцентом,
  тонкими рамками, вращающимся пунктирным кольцом у логотипа и бегущей линией в шапке.
- Кнопка **«Удалить все»** в группе экспериментальных стратегий: удаляет всю группу разом,
  активная стратегия остаётся.

### Изменено

- Блок стратегий переработан: карточки с акцентной полосой, метрики с подписями
  (Discord / YouTube / контроль / задержка), крупный балл и отдельный вердикт.
- Тумблеры и переключатели приведены к единому виду в обеих темах.
- Осталось две темы — «Спутник» (по умолчанию) и «Кармин»; «Тёмная», «Серая» и «Трафарет»
  удалены, старые настройки автоматически переносятся.
- При выходе из приложения обход Discord/YouTube теперь останавливается вместе с
  Telegram-прокси: служба `zapret` переводится в «остановлена» через SCM, без запуска
  `sc.exe`. Автозапуск при входе в систему по-прежнему поднимает обход.

### Исправлено

- Шрифт интерфейса снова Inter, как в 1.3.0 — без замены на узкие технические гарнитуры.

## [1.3.0] — 2026-11-11

### Изменено

- Приложение теперь называется **Splitline**: новое лого — трафаретный плакат «SPLIT LINE»
  в окне, трее и на ярлыке.
- Темы: вместо «Светлой» — **«Кармин»** (тёмная, малиновый акцент), и добавлена
  **«Трафарет»** — бумага, чёрная тушь и красный, с плакатными заголовками и другими кнопками.
- Версия Telegram-прокси показывается по проекту Flowseal (`1.11.4`), без номера нашей сборки;
  ссылка «Что нового» ведёт в [Flowseal/tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy).
  Пересборки той же версии снова предлагаются как обновление.
- Тема хранится в настройках как раньше: у кого была выбрана «Светлая», увидят «Кармин».

### Исправлено

- При выключении или завершении сеанса Windows больше не появляется окно
  «taskkill.exe — Ошибка приложения (0xc0000142)»: приложение не запускает системные утилиты
  при выходе, а завершает свои процессы напрямую.
- Состояние службы и `winws.exe` читается без запуска `sc.exe` и `tasklist.exe` — вместе с ним
  ушли мигающие консольные окна при обновлении интерфейса.
- Telegram-прокси и временные `winws.exe` завершаются вместе с приложением, даже если оно было
  закрыто аварийно.

## [1.2.3] — 2026-10-23

### Добавлено

- На главной странице появилась строка обновления **Telegram WS-прокси** — как у приложения
  и flowseal-zapret; кнопка «Проверить» на главной проверяет все три обновления.
- Если прокси запущен, но Telegram им не пользуется, страница «Telegram» показывает
  подсказку с кнопкой «Подключить Telegram». При первом запуске приложение один раз само

- Порт по умолчанию — **1555** (1443 — конвенция самого tg-ws-proxy, чтобы не конфликтовать
  с ним). При миграции с внешнего TgWsProxy порт наследуется из его конфига.

### Исправлено

- Подсказка «Telegram не подключён» и авто-открытие ссылки теперь реагируют на фактическое
  подключение клиента сразу, а не ждут минутного `stats`-отчёта: подключённый Telegram больше
  не получает лишний диалог добавления прокси.
- «Занять свободный порт» сбрасывает признак открытой ссылки и перезапускает уже запущенный
  прокси, поэтому новая ссылка предлагается автоматически.
- Ручное «Открыть в Telegram» помечает подсказку использованной — второй диалог не откроется.
- Одно нажатие «Проверить обновления» на главной показывает один итоговый тост вместо трёх.
- Если проверку обновлений выполнить не удалось (нет сети, лимит GitHub), главная больше
  не пишет «Обновлений нет», а сообщает, что проверка не удалась.

  главного окна; при выходе приложение его останавливает, сирот не остаётся.
- Собственный headless-бинарник прокси собирается из открытого
  [Flowseal/tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy) и скачивается по
  требованию; в приложении есть проверка и установка обновлений прокси — на странице
  «Telegram» и в «Настройках», рядом с обновлениями приложения и flowseal-zapret.
- Просмотр логов прокси на странице «Telegram» и в файле `tgws\tgws.log`.

### Изменено

- Карточка Telegram на главной больше не заглушка: показывает состояние, адрес,
  версию и переключатель.

## [1.1.0] — 2026-10-20

### Добавлено

- Проверка стратегий: Discord/YouTube/контрольные хосты, baseline без обхода,
  баллы и вердикты, история в `bench.json`.
- Подбор экспериментальных стратегий мутациями топ-3, группа «Экспериментальные»,
  `generated.json`.
- Применение победителя с отложенной перепроверкой и автооткатом (opt-in).
- Мастер-подсказка первого запуска: скачивание runtime в один клик.
- Дизайн-токены, панели с шагами, компоненты Vue, модальные подтверждения,
  тосты, доступность с клавиатуры.
- Нативный заголовок Windows 11 с тёмным caption и системными кнопками.
- Проверка `sha256` ассета runtime, защита от zip-slip, абсолютные пути System32.
- Автообновление приложения по схеме tg-ws-proxy: GitHub latest → SHA-256 → замена exe →
  перезапуск с ожиданием старого PID и резервной копией для отката.
- Мастер первого запуска: выбор папки runtime (по умолчанию `%LOCALAPPDATA%\zapret-ui\runtime`),
  выбор существующей папки, скачивание и установка.
- `runtime_path` в конфиге и смена папки runtime в настройках (только при остановленном обходе).
- CI: fmt, clippy, тесты и сборка фронтенда; release workflow.

### Изменено

- Версия приложения 1.1.0; версия runtime показывается отдельно.
- Остановка обхода, обновление, полная проверка и удаление экспериментальной
  стратегии требуют подтверждения.
- Клик по стратегии только выбирает её; применение — отдельной кнопкой.
- Окно 1040×720, минимум 760×560; проверка попадания на видимый монитор.
- Только Windows 11 (build ≥ 22000), без кросс-платформенных заглушек.

### Исправлено

- Zip-slip и traversal в имени ассета при обновлении runtime.
- Гонка записи `config.json`; запись теперь атомарная.
- Ошибка обновления/бенча больше не оставляет систему без обхода.
- Watchdog не поднимает обход после ручной остановки.
- Кнопка «Открыть папку runtime» работает через `ShellExecuteW`.
- Панели сайдбара не выходят за карточки на коротких/узких окнах.
- `config.json` с UTF-8 BOM больше не сбрасывает настройки при чтении.
