# Changelog

Все заметные изменения проекта. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [SemVer](https://semver.org/lang/ru/).

## [1.6.1] — 2026-11-12

### Добавлено

- Поддержка **Windows 10 22H2** (build 19045.6456 и новее): приложение запускается
  и на «десятке» с актуальным накопительным обновлением. Windows 11 поддерживается
  как раньше. Проверка ОС при старте сравнивает и номер сборки, и ревизию обновления
  (UBR) — без подходящей сборки показывается понятное сообщение вместо запуска.
- Проверка WebView2 Runtime при старте: на Windows 10 без WebView2 вместо молчаливого
  выхода появляется окно с объяснением и ссылкой на установку.

### Изменено

- Атрибуты заголовка, существующие только в Windows 11 (цвет caption, DWM 35/36),
  применяются только на Windows 11; на Windows 10 они больше не вызываются.
- Мастер первого запуска, README, SPEC, описания пакета и имя CI-задачи больше не
  ограничивают приложение только Windows 11.

## [1.6.0] — 2026-11-12

### Добавлено

- Активная стратегия закреплена первой строкой списка: при смене она поднимается
  наверх и больше не дублируется в своей группе.
- Смена стратегии видна визуально: строки переставляются плавной анимацией,
  у применённой плашки — зелёная подсветка фона и короткое «гало» при назначении.
  В режиме `prefers-reduced-motion` обе анимации отключены.

## [1.5.1] — 2026-11-12

### Изменено

- В релиз больше не публикуется `zapret-ui.exe` — побайтовая копия под прежним
  именем, которую оставляли для автообновления клиентов 1.2.x. Их апдейтер искал
  ассет строго по старому имени, поэтому обновление с 1.2.x теперь только вручную.

## [1.5.0] — 2026-11-12

### Добавлено

- Плавные переходы между вкладками: кроссфейд со сдвигом, каскадное появление
  карточек и анимация заголовка в шапке.
- Анимации иконок в сайдбаре при наведении — у каждой вкладки свой характер —
  и акцентное свечение у кнопок, пунктов меню, фильтра сортировки, строк
  стратегий и других кликабельных элементов. Работает в обеих темах и
  отключается при `prefers-reduced-motion`.

### Изменено

- Первичные кнопки темы «Спутник» больше не слепят: градиент глубже, широкий
  бирюзовый ореол заменён мягкой тенью, текст тёмный вместо белого на светлом.
- В релиз больше не попадает `SHA256SUMS.txt`: GitHub публикует digest каждого
  ассета, и апдейтер проверяет именно его.

### Исправлено

- Тулбар стратегий снова с внутренними отступами: устаревшее правило 1.1.0
  обнуляло их, из-за чего подписи и кнопки липли к рамке.
- Прогресс-бар проверки больше не выглядит ошибкой: видимый трек и заливка
  акцентом вместо градиента в красный.
- Слайдер «Подбор новых» и чекбокс «Учитывать экспериментальные стратегии»
  оформлены в цветах темы, а не нативными контролами Windows.

## [1.4.0] — 2026-11-11

### Добавлено

- Новая тема **«Спутник»** — тёмно-синий «орбитальный» интерфейс с циановым акцентом,
  тонкими рамками, вращающимся пунктирным кольцом у логотипа и бегущей линией в шапке.
- Кнопка **«Удалить все»** в группе экспериментальных стратегий: удаляет всю группу разом,
  активная стратегия остаётся.

### Изменено

- Блок стратегий переработан: карточки с акцентной полосой, метрики с подписями
  (Discord / YouTube / контроль / задержка), крупный балл и отдельный вердикт.
- Тумблеры и переключатели приведены к единому виду в обеих темах.
- Осталось две темы — «Спутник» (по умолчанию) и «Кармин»; «Тёмная», «Серая» и «Трафарет»
  удалены, старые настройки автоматически переносятся.
- При выходе из приложения обход Discord/YouTube теперь останавливается вместе с
  Telegram-прокси: служба `zapret` переводится в «остановлена» через SCM, без запуска
  `sc.exe`. Автозапуск при входе в систему по-прежнему поднимает обход.

### Исправлено

- Шрифт интерфейса снова Inter, как в 1.3.0 — без замены на узкие технические гарнитуры.

## [1.3.0] — 2026-11-11

### Изменено

- Приложение теперь называется **Splitline**: новое лого — трафаретный плакат «SPLIT LINE»
  в окне, трее и на ярлыке.
- Темы: вместо «Светлой» — **«Кармин»** (тёмная, малиновый акцент), и добавлена
  **«Трафарет»** — бумага, чёрная тушь и красный, с плакатными заголовками и другими кнопками.
- Версия Telegram-прокси показывается по проекту Flowseal (`1.11.4`), без номера нашей сборки;
  ссылка «Что нового» ведёт в [Flowseal/tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy).
  Пересборки той же версии снова предлагаются как обновление.
- Тема хранится в настройках как раньше: у кого была выбрана «Светлая», увидят «Кармин».

### Исправлено

- При выключении или завершении сеанса Windows больше не появляется окно
  «taskkill.exe — Ошибка приложения (0xc0000142)»: приложение не запускает системные утилиты
  при выходе, а завершает свои процессы напрямую.
- Состояние службы и `winws.exe` читается без запуска `sc.exe` и `tasklist.exe` — вместе с ним
  ушли мигающие консольные окна при обновлении интерфейса.
- Telegram-прокси и временные `winws.exe` завершаются вместе с приложением, даже если оно было
  закрыто аварийно.

## [1.2.3] — 2026-10-23

### Добавлено

- На главной странице появилась строка обновления **Telegram WS-прокси** — как у приложения
  и flowseal-zapret; кнопка «Проверить» на главной проверяет все три обновления.
- Если прокси запущен, но Telegram им не пользуется, страница «Telegram» показывает
  подсказку с кнопкой «Подключить Telegram». При первом запуске приложение один раз само
  открывает ссылку подключения в Telegram — остаётся подтвердить добавление одним нажатием.
- В статусе прокси видно число подключений клиента.
- Порт по умолчанию — **1555** (1443 — конвенция самого tg-ws-proxy, чтобы не конфликтовать
  с ним). При миграции с внешнего TgWsProxy порт наследуется из его конфига.

### Исправлено

- Подсказка «Telegram не подключён» и авто-открытие ссылки теперь реагируют на фактическое
  подключение клиента сразу, а не ждут минутного `stats`-отчёта: подключённый Telegram больше
  не получает лишний диалог добавления прокси.
- «Занять свободный порт» сбрасывает признак открытой ссылки и перезапускает уже запущенный
  прокси, поэтому новая ссылка предлагается автоматически.
- Ручное «Открыть в Telegram» помечает подсказку использованной — второй диалог не откроется.
- Одно нажатие «Проверить обновления» на главной показывает один итоговый тост вместо трёх.
- Если проверку обновлений выполнить не удалось (нет сети, лимит GitHub), главная больше
  не пишет «Обновлений нет», а сообщает, что проверка не удалась.

## [1.2.2] — 2026-10-22

### Исправлено

- При первом запуске встроенный прокси наследует ключ и адрес внешнего `TgWsProxy`
  (если он установлен) — существующая ссылка в Telegram продолжает работать без
  повторного добавления прокси.
- Если порт занимает `TgWsProxy_windows.exe`, приложение останавливает его и занимает
  порт (как Slipgate); для любого другого процесса предлагается соседний свободный порт.
- Сообщение о занятом порте теперь показывает процесс-владелец.

## [1.2.1] — 2026-10-22

  прокси переезжает на соседний свободный порт, ссылка обновляется.

## [1.2.0] — 2026-10-22

### Добавлено

- **Telegram WS-прокси** на странице «Telegram»: включение одной кнопкой, готовая

  «Telegram» и в «Настройках», рядом с обновлениями приложения и flowseal-zapret.
- Просмотр логов прокси на странице «Telegram» и в файле `tgws\tgws.log`.

  версию и переключатель.

## [1.1.0] — 2026-10-20

### Добавлено

- Проверка стратегий: Discord/YouTube/контрольные хосты, baseline без обхода,
  баллы и вердикты, история в `bench.json`.
- Подбор экспериментальных стратегий мутациями топ-3, группа «Экспериментальные»,
  `generated.json`.
- Применение победителя с отложенной перепроверкой и автооткатом (opt-in).
- Мастер-подсказка первого запуска: скачивание runtime в один клик.
- Дизайн-токены, панели с шагами, компоненты Vue, модальные подтверждения,
  тосты, доступность с клавиатуры.
- Нативный заголовок Windows 11 с тёмным caption и системными кнопками.
- Проверка `sha256` ассета runtime, защита от zip-slip, абсолютные пути System32.
- Автообновление приложения по схеме tg-ws-proxy: GitHub latest → SHA-256 → замена exe →
  перезапуск с ожиданием старого PID и резервной копией для отката.
- Мастер первого запуска: выбор папки runtime (по умолчанию `%LOCALAPPDATA%\zapret-ui\runtime`),
  выбор существующей папки, скачивание и установка.
- `runtime_path` в конфиге и смена папки runtime в настройках (только при остановленном обходе).
- CI: fmt, clippy, тесты и сборка фронтенда; release workflow.

### Изменено

- Версия приложения 1.1.0; версия runtime показывается отдельно.
- Остановка обхода, обновление, полная проверка и удаление экспериментальной
  стратегии требуют подтверждения.
- Клик по стратегии только выбирает её; применение — отдельной кнопкой.
- Окно 1040×720, минимум 760×560; проверка попадания на видимый монитор.
- Только Windows 11 (build ≥ 22000), без кросс-платформенных заглушек.

### Исправлено

- Zip-slip и traversal в имени ассета при обновлении runtime.
- Гонка записи `config.json`; запись теперь атомарная.
- Ошибка обновления/бенча больше не оставляет систему без обхода.
- Watchdog не поднимает обход после ручной остановки.
- Кнопка «Открыть папку runtime» работает через `ShellExecuteW`.
- Панели сайдбара не выходят за карточки на коротких/узких окнах.
- `config.json` с UTF-8 BOM больше не сбрасывает настройки при чтении.
